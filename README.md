## About

Frontend part of a multi-user video game store. Developed as a course project at BSUIR, Faculty of Computer Design, 2025.

The interface communicates with a Spring Boot REST API, supporting the full user cycle: registration, browsing, cart management, and order placement.

---

## Tech Stack

- React 19, TypeScript
- Node.js 24
- CSS
- REST API integration

---

## Features

- User registration and login with form validation
- Game catalog with product cards
- Detailed product page
- Shopping cart with quantity controls
- Order checkout
- Admin panel for product and order management
- Responsive design
